LimDent Auto Body Technologies - Vercel Deploy Package
=======================================================

HOW TO DEPLOY ON VERCEL IN 60 SECONDS (FREE):
1. Unzip this folder on your computer.
2. Push the folder to a new GitHub repo (e.g., limdent-demo), OR install Vercel CLI and run `vercel` inside this folder.
3. In Vercel, click "Add New Project" -> Import your repo -> Deploy (Framework Preset: Other).
4. Share your live preview link (e.g. https://limdent-demo.vercel.app) with LimDent!

BEFORE GOING LIVE FOR THE PAYING CLIENT:
- Remove the top "Concept Preview" banner div in index.html.
- Remove `<meta name="robots" content="noindex, nofollow" />` in index.html AND delete vercel.json so Google indexes the site.
- If they moved premises, swap `images/workshop.jpg` with their new building photo.
- Update the WhatsApp number (`27152926518`) in index.html if they prefer a mobile WhatsApp cell number over their landline.
